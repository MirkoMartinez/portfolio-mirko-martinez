# Portfolio - Mirko Martinez

**Descripción:**
Portfolio web personal desarrollado como actividad integradora de la Unidad 3. Este proyecto presenta mi información académica, experiencia como Community Manager y desarrollador, habilidades tecnológicas y los proyectos en los que he trabajado.

**Tecnologías utilizadas:**
* **HTML5:** Estructuración semántica.
* **CSS3:** Diseño visual utilizando Flexbox para el menú, CSS Grid para la galería de proyectos y Media Queries para el diseño responsive.
* **JavaScript:** Interactividad, manipulación del DOM y validación de formularios en tiempo real.

**Principales funcionalidades:**
* Diseño adaptable a dispositivos móviles y escritorio.
* Tarjetas de presentación de proyectos.
* Formulario de contacto interactivo que valida campos vacíos y genera mensajes dinámicos sin recargar la página.

**Instrucciones de uso:**
1. Clonar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web moderno.
